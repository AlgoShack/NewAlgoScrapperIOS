How Scraping Works in algoScraper

                    Element-by-Element inspection, Full Scrape UI, and Viewport Dual-Mode streaming
                

            


            

                
                

                    

                        MODE 1: POINT & INSPECT
                        
Element-by-Element Scraping (Tap Mode)

                    

                    

                        Hover and click on any visual UI element in the live mobile mirror to extract precise node attributes and candidate locators.
                    

                    

                        

                            1
                            

                                Real-Time Coordinate Mapping: Cursor movements over the device stream map directly to screen pixels, calculating bounding box rects from the active XML page source.
                            

                        

                        

                            2
                            

                                Attribute Extraction: Clicking any node extracts Resource ID, Accessibility ID (content-desc / label), Class, Text, Bounds, Clickable, and Package metadata.
                            

                        

                        

                            3
                            

                                Control ID Dropdown Generation: Computes the full multi-XPath candidate set and adds the row into the table with a selectable locator dropdown.
                            

                        

                    

                    

                        💡
                        Interactive Viewport: Switch between Tap Mode (inspect elements) and Device Interact Mode (live touch, drag-to-scroll, and soft keyboard input) directly in the viewport header.
                    

                


                
                

                    

                        MODE 2: BULK EXTRACTION
                        
Full Scrape UI (Whole Screen)

                    

                    

                        Instantly harvests and categorizes every interactive widget on the current mobile screen with a single click.
                    

                    

                        

                            1
                            

                                XML Hierarchy Harvest: Initiates an Appium page source extraction (UiAutomator2 XML or XCUITest hierarchy) with automated screen signature verification.
                            

                        

                        

                            2
                            

                                Smart Widget Filtering: Filters out passive layout wrappers and captures buttons, input fields, checkboxes, list items, text views, images, and dropdowns.
                            

                        

                        

                            3
                            

                                Batch Table Population: Generates semantic Control Names, assigns them to the active Page, and populates multi-XPath candidates for every control.
                            

                        

                    

                    

                        🚀
                        Pro-Tip: When navigating to a new screen in your app, click Scrape UI to populate all controls at once, then refine names or remove unwanted rows.
                    

                    

                        ✨
                        Multi-Delete & Batch Cleanup: Right-click the table header (or click the delete icon) to enable Multi-Delete Mode, select multiple element rows with checkboxes, and batch remove them.
                    

                

            


            
            

                

                    VIEWPORT DUAL-MODE ENGINE
                    
Live Device Interaction vs. Element Inspection

                

                

                    

                        

                            🔍 Inspect Mode (Tap = Scrape)
                        

                        
Clicking on the screen highlights element geometry and extracts the element into the Scraped Table without triggering on-device actions.

                        
    
                            
  • 🎯 Live bounding box highlight on hover
    • 
                            
  • 📋 Full attribute inspector & multi-XPath calculation
    • 
                            
  • 🛡️ Safe exploration without altering app screen state
    • 
                        

                    

                    

                        

                            📱 Interact Mode (Live Touch & Gestures)
                        

                        
Mouse clicks, drags, and keystrokes are transmitted directly to the physical device or simulator via Appium / W3C WebDriver.

                        
    
                            
  • 👆 Single tap, long press, double tap
    • 
                            
  • 📜 Natural click-and-drag for scrolling & swiping
    • 
                            
  • ⌨️ Soft keyboard typing & hardware navigation keys
    • 
                        

                    

                

            

        


        
        

            

                

                    
                

                

                    
Smart Multi-Locators & XPath Storage Engine

                    How algoScraper generates, prioritizes, and stores multi-strategy locators for robust test automation
                

            


            

                

                    algoScraper’s getAllPossibleXPaths engine analyzes each captured XML node and computes a resilient multi-tier locator suite. In the Scraped Table, every row features an interactive CONTROL ID Dropdown allowing you to choose the primary locator, while all fallback locators are permanently stored in the project repository JSON.
                


                

                    

                        
Tier 1

                        
Strong Attribute Locators (Tagged & Wildcard)

                        //*[@resource-id='...'] | //*[@content-desc='...'] | //*[@name='...']
                        
Generates both tag-qualified (//android.widget.Button[@resource-id="..."]) and universal wildcard (//*[@resource-id="..."]) paths for Resource ID, Accessibility ID, text, and label.

                    


                    

                        
Tier 2

                        
Combined Multi-Attribute Locators

                        //tag[@resource-id='...' and @text='...']
                        
Pairs multiple stable attributes (e.g. ID + Text, ID + Content-Desc, or iOS Name + Label) to disambiguate identical elements on real devices.

                    


                    

                        
Tier 3

                        
Parent-Context Relative XPaths

                        //ancestor[@attr='...']//targetTag[@attr='...']
                        
Traverses parent containers to find a stable ancestor with a strong attribute, creating scoped relative paths (e.g. inside list items, cards, or form rows).

                    


                    

                        
Tier 4

                        
Scoped Indexed Paths

                        (//ancestor[@attr='...']//targetTag)[1]
                        
When multiple identical child elements exist inside a parent container, calculates 1-indexed relative positions guaranteed to point to that specific child.

                    


                    

                        
Tier 5

                        
Global Indexed Tag Paths

                        (//android.widget.EditText)[2]
                        
Global index-based tag path evaluated across the entire XML hierarchy tree as a resilient fallback for generic widgets lacking IDs.

                    


                    

                        
Tier 6

                        
Structural Unique Tree XPath

                        //hierarchy/android.widget.FrameLayout[1]/...
                        
Full hierarchical DOM tree trajectory computed by the structure resolver as the ultimate safety net.

Frequently Asked Questions & Troubleshooting

                    Quick solutions for common connection, scraping, locator, and batch workflow scenarios
                

            


            

                
                

                    
                    

                        
                        

                            

                                
                                Android
                            

                            
Ensure USB Debugging is enabled under Developer Options on your phone and accept the RSA computer authorization prompt. Run adb devices in Command Prompt or PowerShell to verify that the device is listed as device (not unauthorized or offline). If missing, ensure OEM USB drivers are installed.

                        

                        
                        

                            

                                
                                Android
                            

                            
Ensure USB Debugging is enabled under Developer Options on your phone and accept the RSA computer authorization prompt. Run adb devices in Terminal to verify that the device is listed as device (not unauthorized or offline).

                        

                        
                        

                            

                                
                                iOS
                            

                            
Ensure Xcode and command line tools are installed. On physical iPhones, trust Developer Certificates under iOS Settings > General > VPN & Device Management and verify WebDriverAgentRunner is installed. For iOS Simulators, verify that the simulator is booted in Xcode.

                        

                    

                


                
                

                    
                    

                        
                        

                            

                                
                                Android
                            

                            
Run adb shell cmd package resolve-activity --brief <package-name> while the app is running, or inspect the APK using Android Studio / APK Analyzer to locate the exported Launcher Activity.

                        

                        
                        

                            

                                
                                iOS
                            

                            
Inspect your app's Info.plist file for the CFBundleIdentifier key, or run ideviceinstaller -l in your terminal to list installed app bundle identifiers.

                        

                    

                


                
                

                    
                    

                        

                            

                                
                                Scraped Table
                            

                            
Right-click the table header or click the delete column header to toggle Multi-Delete Mode. Individual checkboxes appear for each row alongside a master Select All checkbox in the header. Select the rows you wish to remove and click the red Delete Selected button (or press Delete⌫ Backspace) to batch delete them with a single confirmation.

                        

                        

                            

                                
                                Repository
                            

                            
In the Repository tab, click the Multi-Delete button in the project search toolbar to enter multi-select mode. Select target project workspace cards or click Select All Projects, then click Delete Selected to purge multiple projects at once. Active/live project sessions are protected automatically.
